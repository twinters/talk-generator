# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 4.x     | :white_check_mark: |
| < 4.0   | :x:                |

## Reporting a Vulnerability

Please report vulnerabilities privately through GitHub's
[security advisories](https://github.com/twinters/talk-generator/security/advisories/new)
instead of opening a public issue.
